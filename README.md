# Block Dodger — Neon Coin Run

A fast canvas arcade game: steer the paddle, dodge falling blocks, catch coins, and chase a high score. Runs offline with Node 22 and a modern browser.

## Play locally

```sh
node serve.ts
```

Open <http://localhost:8080>. Use **A/D**, **arrow keys**, or drag/touch to move. Press **Space** or click to start and **P** to pause.
